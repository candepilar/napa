# Napa

Anegamiento campo por campo con el radar de la NASA (NASA OPERA DSWx-S1, derivado de Sentinel-1). NASA Space Apps Challenge 2026, desafío "Dancing with the SARs".

- `index.html`: presentación en tres actos (lo que nadie vio, tu campo, todos los campos). `index.html#campo` es la versión para celular.
- `visor.html`: visor técnico con capas NISAR, Sentinel-1, dibujo y medición de lotes.
- `proxy.js`: proxy opcional si el servidor titiler-cmr bloquea las consultas del navegador.
- `napa_pipeline_v03.js`: la misma medición en Google Earth Engine.

Ver `LEEME.md`.
